Overview

This tool takes papers published in the International Journal of Astrobiology (IJA), collects every work they cite, keeps the ones published in biology journals, and checks whether those works' abstracts use the word astrobiology.

Pick a date range in the sidebar and press Run analysis.

Data: Crossref (IJA papers & reference lists), OpenAlex (cited works, journal topics, abstracts), Europe PMC (fallback abstracts). Runs entirely in your browser · Source on GitHub (MIT).
